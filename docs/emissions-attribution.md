# Атрибуция модели выбросов HBEFA

Раздел описывает происхождение коэффициентов и формул в модуле
`trafficmcmt_emissions` (`include/trafficmcmt/emissions/HbefaEmissionModel.h`,
`src/emissions/HbefaEmissionModel.cpp`). Он обязателен к обновлению при любом
изменении таблицы коэффициентов или формулы.

референс для сверки, а не часть сборки.

## Что перенесено

### Таблица коэффициентов

Перенесены ровно три класса `SUMO` (по 36 коэффициентов: `CO2[0..5]`,
`CO[6..11]`, `HC[12..17]`, `FUEL[18..23]`, `NOx[24..29]`, `PMx[30..35]`):

| SUMO ID | Индекс строки в эталоне | Где используется |
|---|---|---|
| `SVE_HDV_6_6` | 8 | `truck`, `bus` |
| `SVE_P_LDV_7_1` | 21 | `motorbike` |
| `SVE_P_LDV_7_7` | 27 | `car`, `unknown` |

Классы `bike`, `person` дают нулевые ставки и таблицы не требуют. Остальные
строки HBEFA (легковые с другими кластерами, автобусы с CNG и т.п.) не
переносились — их нет в текущем маппинге `ObjectType`.

Значения в `src/emissions/HbefaEmissionModel.cpp` совпадают с эталоном
побитово (десятичные литералы `double`), включая нулевой блок `PMx` у
`P_LDV_7_1`.

### Формула

`HbefaEmissionModel::ComputeUsing` — прямой порт `HelpersHBEFA::computeUsing`:

```
v      = speed_kmh
alpha  = asin(a_mps2 / 9.81) * 180 / pi      (a < 0 -> 0)
rate_gps = max((f0 + f1·alpha·v + f2·alpha²·v + f3·v + f4·v² + f5·v³) / 3600, 0)
```

Отличия от эталона (осознанные, задокументированы в заголовке класса):

1. **Кламп отрицательного ускорения.** Эталон возвращает `0` при `a < 0`; это
   оставляет «дыры» в карте концентраций при торможении. По умолчанию
   `clamp_negative_acceleration = true` заменяет `a` на `0` (режим холостого
   хода). Для побитового соответствия эталону задайте
   `emissions.clamp_negative_acceleration: false`.
2. **Ограничение скорости.** `Rates` клампит вход к `kMaxHbefaSpeedMps`
   (130 км/ч): кубический член вне диапазона таблицы даёт физически
   бессмысленные значения. Сам `ComputeUsing` не клампит и остаётся точным
   портом — это позволяет тестам сверяться с эталоном напрямую.

### Производные величины

| Величина | Формула | Комментарий |
|---|---|---|
| `PM10` | `PMx` | эталонная ставка HBEFA |
| `PM2.5` | `PMx × pm25_fraction` | по умолчанию `0.5`, настраивается |
| `NOx`, `CO`, `CO2` | соответствующие блоки | без изменений |

`HC` и `FUEL` переносятся в таблице (чтобы индексы совпадали с эталоном), но в
`EmissionRates` не попадают: в viewer-протоколе пять полей.

## Лицензионный статус

TrafficMCMT распространяется по Apache-2.0 (см. `LICENSE`). Перенесённые
числовые коэффициенты и формула происходят из кода под GPL-2.0-or-later.

Принятое решение (Этап 2c): таблица и формула портированы с явной атрибуцией,
модуль остаётся в дереве под Apache-2.0. Это осознанный компромисс ради
проверяемости расчётов; **перед публичным распространением бинарников или
исходников модуля вопрос совместимости лицензий должен быть пересмотрен
юристом**. Практические варианты, если потребуется:

- вынести `HbefaEmissionModel` в отдельный GPL-2.0+-модуль/пакет;
- заменить таблицу на модель с совместимой лицензией (например, собственную
  калибровку или COPERT с отдельной лицензией);
- оставить таблицу только в тестовых данных, а в поставку включать
  пользовательскую модель через `IEmissionModel`.

До пересмотра в исходниках сохраняется ссылка на этот документ.
